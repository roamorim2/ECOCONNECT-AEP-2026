# EcoConnect - PoC (Primeira Entrega)

## 📌 Problema
O descarte inadequado de resíduos recicláveis e eletrônicos gera poluição e reduz a eficiência da reciclagem urbana. A falta de informações centralizadas dificulta a localização de pontos de coleta adequados pela população.

## 🎯 Alinhamento com a ODS
- **ODS 12 - Consumo e Produção Responsáveis:** Promove a gestão ecologicamente correta dos resíduos e estimula a reciclagem por meio da localização acessível de pontos de coleta.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java 17 (LTS)
- **Framework:** Spring Boot
- **Banco de Dados:** MongoDB (NoSQL)
- **Testes Unitários:** JUnit 5 e Mockito
- **Cobertura de Código:** JaCoCo / IntelliJ Coverage

## 🚀 Como Executar o Projeto

### Pré-requisitos
- JDK 17 instalado
- Maven
- Instância do MongoDB em execução (`mongodb://localhost:27017/ecoconnect`)
